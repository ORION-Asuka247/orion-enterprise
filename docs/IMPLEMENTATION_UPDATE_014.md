# ORION Enterprise Update 014 - Guided Inspection Engine

## Purpose

Update 014 converts ORION from an asset register into an operational compliance workflow:

QR / Manual Lookup -> Asset -> Start Inspection -> Guided Rules -> Evidence -> Automatic Defect -> Submit -> Asset History

## New controlled database objects

- `orion_inspection_templates`
- `orion_inspection_template_items`
- `orion_inspection_runs`
- `orion_inspection_answers`
- `orion_inspection_evidence`
- `orion_inspection_defects`

The migration does not delete or replace legacy inspection/defect tables.

## Fire Door v1 template

The first controlled production template includes:

- top gap: 2-4 mm inclusive
- hinge-side gap: 2-4 mm inclusive
- lock-side gap: 2-4 mm inclusive
- self-closing and latching
- intumescent/smoke seals
- hinges
- leaf/frame damage

A measurement outside 2-4 mm fails immediately.

Failed controlled items:
- display a plain-English reason
- require engineer observations
- create a defect automatically
- can require photographic evidence
- provide a suggested remedial action

## Evidence Storage

Update 014 records evidence metadata in the database and uploads images to a private Supabase Storage bucket named:

`inspection-evidence`

Before testing photographic evidence, create that private bucket in Supabase Storage.

Recommended object layout generated by ORION:

`<company-id>/<inspection-id>/<unique-file-name>`

Storage access should be restricted to authenticated members of the relevant company.

## Release sequence

1. Run migration `20260808_014_guided_inspection_engine.sql` in Supabase SQL Editor.
2. Create a PRIVATE Supabase Storage bucket called `inspection-evidence`.
3. Migration 014 installs authenticated company-scoped Storage policies for this bucket.
4. Extract this update.
5. Run `./install.sh`.
6. Review `git status`.
7. Commit and push to GitHub.
8. Wait for Netlify to publish.
9. Open a Fire Door asset.
10. Click `Start inspection`.
11. Test a 3 mm gap (PASS).
12. Test a 5 mm gap with notes and photograph (FAIL + defect).
13. Complete all items and submit.

## Acceptance criteria

- Fire Door template loads.
- 2-4 mm passes.
- <2 mm or >4 mm fails.
- Failed item requires notes where configured.
- Failure creates `orion_inspection_defects`.
- Photo-required failure cannot be submitted without evidence metadata.
- Completed inspection outcome is PASS only when all items pass.
- Manual asset lookup and QR scan routes remain unchanged.
