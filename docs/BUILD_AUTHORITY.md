# ORION Enterprise v1.0 Build Authority

The v1.0 monorepo supersedes separate phase bundles as the active development source.

Core non-negotiable rules:
1. Every tenant-sensitive record is isolated.
2. Every asset supports QR and manual access.
3. Compliance rules are versioned.
4. Completed inspection history is immutable.
5. AI cannot directly change live compliance rules.
6. Regulatory source changes require controlled human review.
7. Commercial workflows cannot alter compliance outcomes.
8. Reports remain traceable to source snapshots and rule versions.
9. Privileged credentials stay server-side.
10. All critical actions are auditable.
