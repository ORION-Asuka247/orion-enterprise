# Regulatory Rule Governance

ORION must distinguish four separate concepts:

1. Primary law
2. Official guidance
3. Standards / certification evidence
4. ORION operational rule

A compliance rule may only become production-approved after a human reviewer verifies the source and its applicability.

## Required production metadata

Before a rule is treated as verified, add:

- authoritative source
- exact title
- publication/version date
- clause/section reference
- territorial applicability
- effective date
- reviewer
- approval date
- interpretation note
- superseded rule reference where applicable

## Prohibited behaviour

ORION AI must not:

- silently alter rule thresholds
- infer a statutory requirement from an unverified blog/article
- overwrite completed inspection logic
- present an AI interpretation as the law
- use demonstration rules as production rules

The Regulatory Intelligence Engine will propose changes. Human approval remains the release gate.
